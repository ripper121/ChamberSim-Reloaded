# PWA Port Progress

Last updated: 2026-10-25

## Current objective

Port ChamberSim Reloaded to an installable PWA with verified behavioral, numerical, file-format, workflow, and visual parity under `AGENTS.md`.

## Current state (working / failing / blocked)

Working, not blocked. The original Qt application and both release CLIs run locally. The PWA source builds successfully. One hundred sixty-five unit tests, the latest typecheck, production build, thirty-eight live Edge end-to-end checks, and dependency audit pass. The generated service worker was verified by an offline browser reload, including the project database and lazy SQLite reader; a right-aligned Sync indicator now reports current/waiting update state and checks or activates the latest version on click. Native System default/Light/Dark theme, 8–20 point application font, rounded-dialog appearance, optional last-session restoration and logging configuration apply and persist. Settings now has the native OK/Apply/Cancel boundary: Apply stays open, Cancel restores the dialog-open appearance/start-up/unit/log snapshot, and source-matching applied solver/database changes plus immediate reset/log actions remain committed. Browser logging keeps the native Warning/console defaults, five severity choices, filtering, timestamp/tag shape and 1 MiB rotation while mapping stderr to DevTools and native files to IndexedDB-backed downloads. Opted-in startup restores durable browser-held copies of uploaded/explicitly saved loads with current edits, tab order, active tab and original-GRT model identity. System/default German, English, French and Italian language choices resolve and persist with native restart semantics. The authoritative Qt catalogs now drive the safety notice, main shell, complete About content, database actions/tabs/filter/counts/source metadata, load workspaces, source-derived property and record schemas, component actions/dialogs, New Load, Settings appearance/start-up/database/units/solver/logging controls, Chronograph import, Powder Fit, Report controls/editor, the burn-rate table, unit converter, solver/result terminology, axes, chart legends, warnings and native error paths. The active UI locale also drives shared unit, load-property, record-editor, New Load and unit-converter number formatting/parsing, including the native locale-first/C-locale fallback. Common dialog buttons mirror Qt's platform translations, and native unit controls remain in File > Settings rather than appearing as non-native title-bar widgets; genuinely browser-only statuses and accessibility labels remain explicitly outside the native catalogs. The main menu now follows the source hierarchy (File, Edit, View with Theme/Language submenus, Tools and Help), with load/history-dependent enablement and native shortcuts. Numerical profiles, persistent solver selection and original-file override, result and measurement charts, original-reference overlays, cartridge/chamber/powder drawings, editable inputs and measurement series, chronograph imports, powder fitting, load reports/printing, burn-rate and unit-converter tools, persistent resizable workspaces, dependent-field rules, deterministic recalculation, dirty state, undo/redo, lossless CSR save, compatible GRT export, native unit preferences, shotshell pressure-group choices, all three database sources, persistent personal-record CRUD/JSON export/photos, manufacturer bullet-file import, New Load, and database-backed component replacement now work. Failed simulations retain the native result structure and exact invalid/capacity/bullet-stuck messages, failed ladder steps, and accepted-overpressure warnings across all three solver profiles. Many secondary workflows remain incomplete.

## Known issues and blockers

- Many secondary interactions are not yet ported. Remaining browser-only status/accessibility wording is explicitly classified rather than presented as desktop-catalog parity. These gaps are tracked as TODO or `IN PROGRESS` rather than hidden or simulated.
- For the tracked measurement fixture, the packaged release CLI's Physical powder fit does not reflect the current source/data's 1.0139 caliber burn-rate factor. The PWA follows current source and differs by under 0.5%; Original fitting matches the release. See D-024.
- Browsers expose PDF creation through the print destination chooser, so Export PDF cannot reproduce the desktop application's direct path-writing dialog. It opens the A4 report in the browser print dialog and tells the user to choose Save as PDF; report content and scale are shared with preview/print.

- Native screenshot mode produced two usable screenshots; one concurrent screenshot process did not exit and was stopped after its executable path was verified.
